# צילום בכל גיל – חנות ציוד צילום

אתר סטטי (GitHub Pages) שמציג ציוד צילום מחנויות רשמיות באלי אקספרס, עם קישורי שותפים.

- `index.html` – האתר. קורא את המוצרים מ-`data/products.json`.
- `data/products.json` – כל המוצרים והאוספים. עדכון מוצרים = עדכון הקובץ הזה בלבד.
- `scripts/refresh.py` + `.github/workflows/refresh.yml` – בדיקה שבועית מול אלי אקספרס (מחיר, דירוג, מוצרים שנעלמו). התוצאה נפתחת כבקשת שינוי שמחכה לאישור.
- הסוד של ה-API נשמר רק ב-Settings → Secrets → Actions בשם `ALI_APP_SECRET`.

## מבצעים וקופונים (data/deals.json)
כשהרשימות ריקות, באתר לא מופיע כלום. כשמוסיפים אירוע או קופון, מופיעים פס עליון ולשונית "מבצעים וקופונים" (#deals). מה שפג תוקפו נעלם לבד.
- events: {"title", "show_from" (מתי להתחיל להציג ספירה לאחור), "start", "end", "text"}
- coupons: {"title" (למשל "10$ הנחה"), "cond" (למשל "בקנייה מעל 69$"), "code", "start"?, "end", "checked" (תאריך בדיקה)}
מוסיפים רק קופונים ותאריכים שנבדקו מול אלי אקספרס, ורק באישור יורם.

## מה מתאים למצלמה שלי (data/cameras.json)
נבנה מ-scripts/camera_data.py: רשימת מותגים ודגמים, ותיוג כל מוצר (for = סוגי מצלמה, models = דגמים מדויקים, brand_for = מותג).
קודי סוללות נלקחים רק מ"מתאים ל" של סוללות שנבדקו. אחרי הוספת מוצרים מעדכנים את הרשימות בסקריפט ומריצים: python scripts/camera_data.py
מותגים לעתיד: פנסוניק ועוד.

## מה חדש השבוע (data/news.json)
גיליון שבועי באזור #news. משימה מתוזמנת של Claude מכינה כל יום ראשון טיוטה בענף news-draft, ויורם מאשר בצ'אט לפני שהיא עולה.

## סריקה שבועית (.github/workflows/brand-scan.yml, יום ראשון 06:30)
- scripts/brand_scan.py – מוצרים חדשים מהחנויות הרשמיות של 14 מותגים → data/brand_new.json (לגיליון השבועי).
- scripts/collection_scan.py – מועמדים לכל אוסף לפי data/collection_queries.json → data/store_candidates.json. כללים: חנות רשמית, דירוג 94%+, 100 מכירות+, עד 200$, עם עמלה. עד 3 לאוסף; Claude ממליץ על עד 5 בשבוע, ונכנס לחנות רק מה שיורם אישר. מסומנים גם מוצרים חלשים (דירוג מתחת ל-92% או שנעלמו) להצעת הסרה.

## מחיר וגרסה מומלצת (variant)
באלי אקספרס המחיר הנמוך בדף מוצר הוא לפעמים של חלק בלבד מהערכה שבתמונה. לכן:
- מוצר בלי variant: המחיר מוצג "החל מ-X$" (המחיר הנמוך ביותר, מתעדכן ברענון השבועי).
- מוצר עם variant (למשל "ערכה מלאה עם קופסת טעינה" או "תקע EU"): השדה מוצג בכרטיס, המחיר מוצג "כ-X$" ונקבע ידנית לגרסה הזו, והרענון לא דורס אותו.
- price של מוצר עם variant נבדק מול דף המוצר לפני ההוספה. הקישור נוצר, כשאפשר, מכתובת שבה הגרסה כבר בחורה.
